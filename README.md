# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- リモートリポジトリ　ネット上で共有できるソースコード置き場
- ローカルリポジトリ　PCにあるソースコード置き場

## プッシュとマージの違いは何でしょうか？
- プッシュはローカルの変更履歴をリモートへ送ること
- マージは同じリポジトリ内にある別ブランチの変更履歴を取り込むこと。

## コミットとプッシュの違い
- コミットは変更履歴を保存すること
- プッシュは変更履歴をローカルからリモートにアップすること

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- 誰が見ても何をしたのかわかるように。かつ簡潔に

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
- 前者はローカル内で実行されるもので、プッシュしない限り共有部(リモート)からは見えない。
- 後者はマージの前にプッシュをしてプルリクエストというフロー。マージを実行する前に、変更履歴がリモートにあがり他メンバーによるレビューが可能になる。マージ依頼を受けた他メンバーがコードレビューし、問題なければマージを実行する。他メンバーのチェックが入るため、バグなどを早期に発見できる可能性が高い。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
- コンフリクトが発生しているファイルを確認し、変更を取り込む必要があり、方法は3通りある。
1. 先にマージされた変更内容を採用
2. 後にマージしようとしている変更内容を採用
3. どちらの変更内容も取り込む

- 1と2の方法はコマンドを使って行えるが、3の方法はコードを確認しながら手作業で消していく作業になるため、間違えないよう注意が必要。
